# Peregrino (CD2) — Amarílio Fontenele

Letras oficiais do álbum, extraídas de
`assets/references/CD2 PEREGRINO as Letras.pdf` (fonte da verdade) e já
convertidas de caixa-alta para o formato usado nos `.lrc` finais. Cada
arquivo `.txt` em `assets/references/` tem um cabeçalho com título, tom e
uma lista **"Conferir com a gravação"** apontando prováveis erros de
digitação do PDF — sempre resolver ouvindo o áudio.
